# Contributing

Thanks for your interest in OpenSig!

## Dev setup

- `docker`, `docker compose`, `node >= 20`, `go >= 1.22`, `dotnet >= 8.0`
- Optional: `gh` GitHub CLI for scripts

## Branching & PRs

- `main` is protected. Use feature branches.
- Conventional Commits are encouraged (e.g., `feat(server): ...`).

## Run locally

See `README.md` and `deploy/docker-compose.yml`.

## Issues & Projects

Use `scripts/create_labels.sh` and `scripts/create_issues.sh` to bootstrap.
